## Título

Modelo Predictivo de Rendimiento Académico: Regresión Lineal para la Toma de Decisiones

## Descripción del Proyecto

Este proyecto aplica técnicas de regresión lineal múltiple para examinar los factores que influyen en el rendimiento académico, específicamente en el Índice de Rendimiento (Performance Index).

El análisis se centra en identificar las variables más significativas y crear un modelo estadísticamente robusto para predecir el éxito estudiantil. Se concluye que el rendimiento está predominantemente determinado por la capacidad intrínseca y el conocimiento previo (Previous Scores) y el tiempo de estudio (Hours Studied).

## Objetivos

    Identificar los factores clave (variables predictoras) que tienen una influencia significativa en el rendimiento académico.

    Construir, evaluar y validar un modelo de regresión lineal con el mejor ajuste (R2 ajustado más alto) y menor error (RMSE) para predecir el Performance Index.

    Confirmar la validez estadística del modelo final mediante el análisis de residuos (homocedasticidad y normalidad).

    Demostrar la irrelevancia de ciertos factores (ej. Horas de sueño o Actividades extracurriculares) para la predicción lineal del rendimiento.

## Herramientas o Lenguajes Utilizados

    Lenguaje: Python

    Librerías Clave:

        Pandas y NumPy: Manipulación y limpieza de datos.

        Scikit-learn / statsmodels: Construcción, entrenamiento y validación de los modelos de regresión.

        Matplotlib y Seaborn: Visualización de datos (Análisis Exploratorio de Datos, gráficos de dispersión y análisis de residuos).

    Entorno: Jupyter Notebook / Google Colab.

## Conjunto de Datos

    Fuente: Dataset sintético diseñado para el análisis del rendimiento académico.

    Tamaño: 10,000 registros de estudiantes.

    Variables (Ejemplos):

        Variable Objetivo: Performance Index (Medida de rendimiento académico total).

        Variables Predictoras: Hours Studied, Previous Scores, Extracurricular Activities, Sleep Hour, Sample Question Papers Practiced.
